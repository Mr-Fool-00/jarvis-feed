## Changes that matter

### 1. MCP `request_timeout_ms` fix (HIGH PRIORITY)

MCP servers configured via `.mcp.json` or `--mcp-config` were **silently ignoring** the `request_timeout_ms` setting and falling back to the 60-second default. This affected any tool call that legitimately takes >60 seconds (file indexing, slow search, long API calls, etc.).

**Impact:** If you have any MCP server with long-running tools, those calls were silently timing out and falling back to error state — with no indication that the configured timeout was being ignored.

**What to do:** After upgrading to v2.1.206, verify your `.mcp.json` timeout configs are being respected. If you'd worked around this by chunking long operations, you can now simplify.

### 2. `/doctor` gained a CLAUDE.md trim check

`/doctor` now analyzes your CLAUDE.md and proposes removing content that Claude could derive from the codebase itself — reducing context bloat without losing coverage.

Run `/doctor` after upgrading. The trim suggestions are worth reviewing — CLAUDE.md entries that describe directory structure or file naming conventions are prime candidates for removal if the codebase is self-describing.

### 3. Background agents auto-upgrade

Background agents (those running in separate agent sessions) now automatically upgrade to new CC versions immediately after an update. Previously they would block on the stale-session upgrade prompt at next attach, which caused version mismatches in long overnight sessions.

**Impact for Jarvis overnight runs:** This means if a new CC version ships mid-session, background agents pick it up automatically rather than running stale. Monitor for any behavior changes after upgrades.

### 4. `/commit-push-pr` remote flexibility

Now respects `remote.pushDefault` (not just `origin`). Useful for non-standard git remote configs.

### 5. Gateway login

`/login` now supports Anthropic-operated public gateway endpoints. Relevant if accessing Claude via enterprise gateway rather than direct API.

### 6. Bug fixes

- Expired login showed misleading "issue with selected model" error → now correctly prompts `/login`
- OAuth MCP servers required manual re-auth after a single failed token refresh → fixed
- `/model` picker showed prices for the wrong rows → fixed
- Bedrock startup hung on restricted-egress networks → fixed

## Upgrade command

```bash
npm update -g @anthropic-ai/claude-code
```

Then run `/doctor` and check CLAUDE.md trim suggestions.
