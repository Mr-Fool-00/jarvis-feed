# Incoming URLs — manual curation funnel

Drop URLs here (one per line) when you see something on Instagram / TikTok / X / anywhere that you want Jarvis to deep-dive on its next run. The agent reads this file, processes every URL via yt-dlp (downloads + frame extract + transcribes), surfaces all of them under the `🎯 Curated by Leo` section at the top of the digest (no score filter — you already pre-filtered by saving them), then clears this file so it's ready for the next batch.

Supported: Instagram Reels, YouTube videos, TikTok, Twitter/X posts, any URL yt-dlp handles.
