### 3. Post-Fable model routing: when to use Opus, Sonnet, and Haiku in your pipelines
**Source:** MindStudio + Developers Digest · **Score:** 7/10

With Fable 5 going behind paywall tonight, two complementary guides dropped this week: MindStudio's AI Model Routing Framework and Developers Digest's "Best Claude Model Now That Fable 5 Is Disabled." The consensus: **Opus 4.8 for long agentic sessions, Sonnet 4.6 as the default workhorse, Haiku 4.5 for high-volume extraction**. The routing principle: use the cheapest model that reliably passes the task — you're optimizing cost-to-quality ratio, not raw quality everywhere.

Specific routing rules from MindStudio:
- **Fable 5 (post-paywall only)**: Reserve for multi-step agentic work where errors are genuinely costly and output drives significant business value
- **Opus 4.8**: Long autonomous runs, browser/computer use, agent teams, deep architecture decisions
- **Sonnet 4.6**: Default for daily coding, code review, extraction, tool use, interactive tasks
- **Haiku 4.5**: Bulk classification, summarization at scale, anything cost-sensitive and high-volume

Also flagged: GPT-5.5 as a tested cross-vendor fallback for when Anthropic models are throttled or suspended.

**Why it matters to Leo:** Your chapter writing pipeline currently probably defaults to the highest available model. After tonight that's expensive if it's Fable. This routing framework maps cleanly to your pipeline stages: planning → Opus, drafting → Sonnet, consistency check → Sonnet, bulk extraction/classification → Haiku. Could halve your per-chapter credit burn.

Build verdict: INFORMATIONAL — the routing logic isn't a novel pattern, but applying it explicitly to your pipeline stages is the action here.
