## What it is

MAGNET is a multi-agent narrative generation framework. Instead of one model generating an entire story, multiple **persona-grounded character agents** each propose actions against a **shared world state** and evolving story goals. A coordinator reconciles proposals and advances the plot.

Companion system: **ATLAS** — a graph-based hallucination detector that builds scene-level knowledge graphs and flags when new scenes contradict established world state (wrong location, dead character re-appearing, timeline breaks).

## Results

- **50% fewer hallucinations** vs. single-model baseline
- **41% less manual annotation burden** (ATLAS catches what humans had to catch)
- Characters maintain **consistent voice** because each agent carries its own persona context instead of fighting for dominance in a shared prompt

## Why this matters for your fiction pipeline

The core problem in long-form generation with a single model: character voices blur, world state drifts, and you spend half your time manually catching contradictions. MAGNET's architecture directly addresses all three.

The **ATLAS detector** is the most immediately useful piece. Even without adopting the full MAGNET orchestration, the idea of building a scene-level world graph and running contradiction checks before committing output is something you could add to your current pipeline as a standalone quality gate.

## Design patterns worth stealing

1. **Separate persona context per character** — each character agent gets its own system prompt with voice, goals, backstory. No shared context pollution.
2. **Shared world state object** — a structured representation of established facts (locations, relationships, timeline) that all agents read from but only the coordinator writes to.
3. **Proposal → reconcile → commit loop** — character agents propose; coordinator arbitrates; only then does the scene get written. Reduces hallucination by separating generation from canonization.
4. **Graph-based contradiction detection** — ATLAS compares incoming scene elements against the world graph. Any node conflict triggers a flag before the scene is committed.
