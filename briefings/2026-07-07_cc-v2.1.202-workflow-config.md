# Briefing: Claude Code v2.1.202 — dynamic workflow size + /review rollback

**Date:** 2026-07-07  
**Score:** 7/10  
**Category:** INFORMATIONAL — changelog  
**ID:** `cc:v2.1.202-workflow-config-july6`

---

## What it is

Claude Code v2.1.202 shipped July 6 at 22:51 UTC. Key changes:

**New features:**
- Dynamic workflow size setting in `/config` — choose small/medium/large to control how many sub-agents spawn in multi-agent runs. Previously this was hardcoded.
- OpenTelemetry integration: `workflow.run_id` and `workflow.name` are now exported as span attributes. Useful for tracing agent runs in production.

**Behavior change (breaking for some):**
- `/review <pr>` has been reverted to single-pass mode. If you want multi-agent PR review, you now have to explicitly call `/code-review <level> <pr#>`. The `/review` shorthand no longer fans out.

**Bug fixes:**
- Remote Control: image and file drops now work again (were broken)
- Git worktree: session resume lag fixed
- Voice dictation: unbounded loop that could spin indefinitely is fixed
- Skill re-invocation: was creating duplicate instructions in context — fixed
- 8+ additional smaller fixes

## Why Leo would want this

The workflow size control in `/config` is genuinely useful for Jarvis — right now the agent fleet size is whatever CC decides. Being able to say "small" for quick discovery runs and "large" for comprehensive audits is a meaningful workflow lever.

The `/review` rollback matters if you've been relying on `/review <pr>` expecting multi-agent behavior — it doesn't do that anymore. Switch to `/code-review high <pr#>` for the multi-pass version.

## Why Jarvis flagged it

CC changelogs in the v2.1.x series have been dense — this one has a behavior change that breaks existing scripts/muscle memory. Better to know now than discover it mid-review.

## What to do

1. Update CC: `npm install -g @anthropic-ai/claude-code@latest` (or auto-updates on next launch)
2. If you have any automation calling `/review <pr>`, swap to `/code-review <level> <pr#>`
3. Try the `/config` workflow size setting on next multi-agent run — "small" for light tasks, "large" for comprehensive runs
4. If you use voice dictation in CC, the unbounded loop fix is worth having
