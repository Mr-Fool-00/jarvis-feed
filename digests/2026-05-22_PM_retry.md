### 5. arxiv:2604.07911 — Dynamic Attentional Context Scoping (DACS)
**Source:** arxiv.org · **Score:** 7/10
In multi-agent orchestration with concurrent agents, they compete for the orchestrator's context window — task state and pending questions contaminate steering interactions. DACS operates in two modes: Registry mode holds lightweight per-agent status summaries (≤200 tokens each); when an agent emits a SteeringRequest, orchestrator enters Focus mode, injecting full context of that agent while compressing all others to registry entries. Result: 90.0-98.4% steering accuracy vs. 21.0-60.0% baseline. Wrong-agent contamination drops from 28-57% to 0-14%.
**Why it matters for Leo:** Your Council pattern has the same problem at smaller scale — when one advisor needs course correction, the correction leaks into the other advisors' context. The "focus session" mechanism (compress all others, expand the one that needs steering) could be implemented as a Council skill modifier.
Build verdict: INFORMATIONAL — interesting multi-agent theory; the implementation requires significant harness work without a concrete skill shape.
🔗 https://arxiv.org/abs/2604.07911
