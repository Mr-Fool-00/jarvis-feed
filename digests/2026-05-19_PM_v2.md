### 2. Claude Code Agent View — multi-session dashboard lands (v2.1.139+)
**Source:** code.claude.com/docs · **Score:** 9/10
`claude agents` opens a full-terminal dashboard showing all background sessions: what's working, what needs input, what's done. Dispatch tasks with a prompt, peek/reply without leaving the dashboard, attach for full conversation, detach back to the table. Sessions run via a supervisor daemon that persists across sleep. Each session auto-isolates in a git worktree. Research preview, requires v2.1.139+. Also introduced: `/goal` command for setting completion conditions, `--bg` flag for shell dispatch, `@agent` dispatch syntax.
**Why it matters:** This is a direct upgrade to your daily workflow. You currently manage parallel agents via tmux/tabs and the Agent tool. Agent View replaces that with a unified dashboard — dispatch a fixer pass, a research task, and a code review simultaneously from one screen. The worktree isolation means parallel sessions don't stomp each other's files. Combined with your existing subagent architecture (context-fetcher, slack-formatter), this could let you run 3-4 writing pipeline stages concurrently without context-switching overhead.
🔗 https://code.claude.com/docs/en/agent-view

### 3. Anthropic launches official Claude Code Plugins directory
