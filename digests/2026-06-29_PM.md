### 2. Narrative Knowledge Weaver — Story-World Reasoning Framework for Long-Form Narrative
**Source:** arXiv:2606.05724 (June 4, 2026) · **Score:** 7/10

The Narrative Knowledge Weaver (NKW) paper proposes a structured framework for source-grounded story-world reasoning. Core contribution: a dynamic knowledge graph that tracks character states, causal chains, and temporal position across a narrative — updated incrementally as chapters are processed, then queried at generation time. Evaluated on NarrativeQA and a new LongFictionBench (100K+ token novels). NKW outperforms retrieval-augmented generation baselines by 11% on temporal consistency and 18% on character-state accuracy. The system uses a graph diffing step: before writing a new chapter, compare current world-state to intended chapter events, surface contradictions.

**Why it matters:** Leo's overnight novel runs are currently bottlenecked by context-window memory drift — characters forget events, world details drift, timelines contradict. NKW's incremental graph approach is exactly the architecture for a fiction pipeline memory layer. The graph diffing step maps directly to a consistency-check pass before each chapter write. The code is available (MIT license): github.com/narrative-knowledge-weaver/nkw. This is worth a dedicated read-through and a spike in Leo's fiction pipeline.
