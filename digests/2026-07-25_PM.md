### 4. vshulcz/deja-vu — Cross-Harness Agent Memory MCP, 84.9% Recall, Fully Local (July 14)
**Source:** github.com/vshulcz/deja-vu · **Score:** 7/10 · **Category: third-party code — safety gate reviewed**

Local-first MCP server that retroactively indexes months of conversation history from 16 coding agents (Claude Code, Cursor, Codex, aider, Gemini CLI, Goose, and more) and makes them searchable in ~12ms. Zero-dependency binary. No LLM needed — pure lexical indexing achieves 84.9% hit@1 on LongMemEval-S. Four MCP tools: `recall` (dense snippet matching), `recall_context` (Markdown session digest), `blame` (which sessions touched a file), `remember` (store durable decisions). Auto-redacts AWS keys, JWTs, and PEM blocks at index time. Security note: `--auto` mode silently injects prior session context into every new agent call — that stream is a prompt injection surface if past sessions included malicious repo content (e.g., a poisoned README that got summarized into memory). Treat the deja-vu index as sensitive data and don't enable `--auto` on untrusted codebases.

### 6. arxiv:2606.04896 — Channel Fracture: Silent Memory Injection Failures in Multi-Agent Pipelines
**Source:** arxiv · **Score:** 6/10

Documents a production failure mode where information routed across agent boundaries is silently dropped — no error raised, no retry triggered, both sides think the delivery succeeded. Three documented instances from a real deployment: cron memory injection blocked by scheduler lifecycle barriers; cross-profile skill routing fractured by recursive directory traversal; WebSocket confirmation fallback fracture causing message duplication (looks correct, corrupts state). Proposed fix: CADVP v1.1, a 13-dimension verification protocol using inverse verification (receiver confirms, not sender). 30,012 controlled trials: zero failure rate with CADVP vs 69–98% without it.

🔗 https://arxiv.org/abs/2606.04896

**Build verdict: INFORMATIONAL** — if you're building cron-based context injection for Jarvis (nightly summaries pushed to agent memory), read the CADVP receiver-confirmation pattern before shipping.
