### 1. Anthropic Managed Agents: Dreaming + Outcomes (Late Catch from May 6)
**Source:** claude.com/blog/new-in-claude-managed-agents · **Score:** 8/10
Announced at CwC SF on May 6, 2026 — never appeared in any prior Jarvis digest despite being directly applicable to Leo's pipeline. Two distinct features:

**Dreaming:** A scheduled background process that reviews agent sessions and memory stores, extracts cross-session patterns, and curates memory so agents improve over time. Mimics hippocampal memory consolidation. Can auto-apply learnings or require human review before changes. Legal AI firm Harvey saw **6x task completion rate increase** after implementing Dreaming. Status: research preview.

**Outcomes:** A quality rubric enforcement layer where you write a description of what success looks like, then a separate "grader agent" — in a completely clean context window, not influenced by the task agent's reasoning — evaluates the output against the rubric. If the threshold isn't met, the grader identifies specific failures and kicks the task back for revision. Creates automatic retry-until-quality loops. Measured improvements: PowerPoint quality +10.1%, Word docs +8.4%, up to 10 percentage points on task success overall. Status: public beta, available now.

**Why it matters:** Outcomes is essentially what Leo needs next in his chapter writing pipeline. The current pipeline has iteration caps (try N times) or heuristic checks. Outcomes implements the external-grader-in-separate-context pattern that Anthropic has now validated at scale — structurally identical to BrightCoding's APPROVED signal and MindStudio's external critic architecture, but available as a first-party managed feature. The rubric format makes quality criteria explicit and auditable. The Dreaming feature addresses the session-level memory gap — each novel-writing run starts cold; with Dreaming, the writing agent would accumulate craft patterns across runs automatically.

🔗 https://claude.com/blog/new-in-claude-managed-agents
**Build verdict: BUILDABLE — Outcomes pattern is the external quality gate Leo's chapter writer is missing; Dreaming is the session memory fix**
