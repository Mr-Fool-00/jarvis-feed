### 3. Claude Code v2.1.170 — /cd, --safe-mode, disableBundledSkills
**Source:** github.com/anthropics/claude-code/releases · **Score:** 6/10  
The Fable 5 update ships three new utility flags worth knowing:

- **`/cd <path>`** — moves a session to a new working directory **without breaking the prompt cache** mid-session. If you're switching between your world-bible directory and active chapter repo in a single writing session, this is the command that makes that seamless.
- **`--safe-mode`** (+ `CLAUDE_CODE_SAFE_MODE` env var) — starts CC with ALL customizations disabled: CLAUDE.md, plugins, skills, hooks, MCP servers. Clean-room troubleshooting without reconfiguring anything.
- **`disableBundledSkills`** setting (+ `CLAUDE_CODE_DISABLE_BUNDLED_SKILLS` env var) — hides bundled skills/workflows/built-in commands from the model context. Useful for testing your custom skills in isolation without bundled noise.

Also fixed: sessions not saving transcripts when launched from VS Code integrated terminal.

**Why it matters:** `/cd` specifically addresses the multi-project session problem. If your book pipeline switches between world-bible and chapter dirs, you've been losing cache on the switch. That cost is now gone.

🔗 https://github.com/anthropics/claude-code/releases
