### 3. Ornith-1.0: Self-Scaffolding Open-Weights LLM for Agentic Coding
**Source:** Simon Willison · simonwillison.net/2026/Jun/29 · **Score:** 5/10

DeepReinforce released Ornith-1.0 on June 29 — open-weights (MIT), purpose-built for agentic coding via self-scaffolding. Four variants: 9B Dense, 31B Dense, 35B MoE, 397B MoE. The defining concept: instead of using a pre-built framework (LangChain, Claude Agent SDK), Ornith generates the minimal scaffolding code for each specific task before executing it. "Writes the plumbing before writing the logic." It starts every task by generating the task-specific agent loop, tool definitions, and handoff conditions — then fills in the actual work. Simon Willison's post is skeptical but notes it produces unusually clean, non-generic orchestration code.

**Why it matters:** Leo is on CC Max and won't use Ornith directly. The pattern is what matters. A "scaffold-first" approach to the novel pipeline would have Claude write the chapter-generation orchestration plan first (which writer agents, in what order, what consistency checks, what the APPROVED condition is) — before running any actual writers. Currently Leo writes the scaffolding as a fixed skill; Ornith's approach suggests generating task-specific scaffolding at runtime. Not immediately actionable, but the signal is real: the field is moving toward agentic code that generates its own orchestration rather than executing a fixed workflow.

🔗 https://simonwillison.net/2026/Jun/29/ornith/

**Build verdict:** INFORMATIONAL — Leo's stack is CC Max + Claude, not open-weights. The self-scaffolding concept is worth filing for future skill design iteration.

### 6. "AI Agents May Always Fall for Prompt Injections" — Multi-Step Chain Compounding
**Source:** arXiv:2605.17634 (May 2026) · **Score:** 5/10
