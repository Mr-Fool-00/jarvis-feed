### 3. Fable 5 edited its own launch video — Thariq's full pipeline (no NLE, zero manual edits)
**Source:** explainx.ai / thariqs.github.io · **Score:** 8/10

Thariq Shihipar (Anthropic CC team) published the full architecture of how Fable 5 autonomously edited the Fable 5 launch video without opening a traditional editor. 288K+ views on X. The pipeline:

1. **Transcription:** 17 video takes → Whisper on M4 Max → per-word JSON timestamps in `work/transcripts/`
2. **Selection:** Subagents picked best shots into `final-edit.json`
3. **Assembly:** ffmpeg cut + concatenated, generated 7 hand-written `.cube` LUTs (S-Log3→Rec.709 color grading) with names like `neutral709`, `warm_filmic`, `punchy`
4. **Motion graphics:** Remotion rebuilt 11 animated design elements from static PNGs
5. **Orchestration:** Figma MCP for design assets, Claude Code as orchestrator throughout

No human in the editing chair. Interactive deck at `thariqs.github.io/cc-video-editing-deck`.

**Why it matters:** This is the exact pattern your book pipeline needs — except in writing. The `transcript → select best takes → grade/polish → assemble` loop maps directly to: `draft chapters → rank/select best → voice-check + continuity-check → compile manuscript`. Thariq is showing you the Fable 5 + Claude Code creative production pattern. The video domain doesn't matter; the architecture does. This is your book pipeline on film.
