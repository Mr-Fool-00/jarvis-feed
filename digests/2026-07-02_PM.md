### 1. CC v2.1.198 — Full Feature Set (PostSession Hook + /dataviz + /cd + Safe Mode)
**Source:** GitHub Releases · Claude Code Changelog · Releasebot · **Score:** 8/10
**Build verdict:** BUILD-WORTHY — PostSession hook is directly actionable for Leo's overnight runs. Briefing committed to `briefings/2026-07-02_postsession-hook.md`.

The AM run captured v2.1.198's security features (sandbox.credentials encryption, tool call audit log) but missed four additional features in the same release:

**PostSession hook** (`postSession` lifecycle event): fires after a Claude Code session ends cleanly — whether via `/quit`, timeout, or background session completion. Can run any shell script. Immediate use case: snapshot open chapter files to git, write a session summary, send a Slack message with what the agent finished. This is the closest thing CC has to "save my work when the session ends" — directly applicable to Leo's overnight fiction runs.

**`/dataviz` skill** (built-in): CC now ships a native design system skill for chart and dashboard generation. Not directly fiction-pipeline relevant, but useful if Leo wants his Jarvis digest stats visualized.

**`/cd` command**: change working directory mid-session without rebuilding the prompt cache. Minor QoL but meaningful in long multi-directory CC sessions.

**`--safe-mode` / `CLAUDE_CODE_SAFE_MODE`**: launch CC with ALL customizations (CLAUDE.md, plugins, skills, hooks, MCPs) disabled. Clean-room troubleshooting. Should be in every developer's toolkit when chasing "why is my session broken."

**`disableBundledSkills` setting**: hide built-in slash commands from the skill list (reduces noise when Leo's project skills are the focus).

**Why it matters for Leo:** The PostSession hook alone is worth a session to implement. An overnight fiction run ends → hook fires → open chapter files get committed to git → Slack message drops in `#general` with what finished. No more "did it finish or just die?" ambiguity.

### 3. Anthropic Officially Confirms Steganography Removed — But Silently
**Source:** TechTimes · ByteIOTA · Singularity.kiwi · **Score:** 6/10
**Build verdict:** INFORMATIONAL — completes the story from AM run's #1 item. No action for Leo.

This closes the loop on the AM run's top item (HN:48734373, 605+ points, steganographic fingerprinting of CC system prompts via Unicode variant selectors when `ANTHROPIC_BASE_URL` points to non-official endpoints).

**What Anthropic confirmed:** The encoding was real. The behavior was intentional — injecting timezone-derived Unicode markers into system prompts routed through proxies with Chinese-locale fingerprints or AI-lab-keyword hostnames. The fix was deployed in v2.1.197 (June 30 release).

**What Anthropic did NOT do:** The v2.1.197 changelog says nothing about removing the steganographic code. No public statement beyond a quiet acknowledgment to the media. Cybernews noted Anthropic "accused of embedding hidden spyware-like code targeting Chinese users" — that's the community's characterization; Anthropic's stated intent was routing telemetry, not surveillance.

**Leo's actual exposure:** CCR (Jarvis's execution environment) uses `ANTHROPIC_BASE_URL` set to the sandbox proxy. All Jarvis routine commits prior to v2.1.197 went through the fingerprinted path. No known practical consequence — the markers were telemetry for Anthropic's routing, not a credential exfiltration. But worth knowing.

🔗 https://www.techtimes.com/articles/319415/20260701/claude-code-hid-proxy-fingerprints-system-prompts-anthropic-promises-fix.htm
