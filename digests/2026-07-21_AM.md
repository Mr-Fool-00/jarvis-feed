### 4. Unpatched Claude for Chrome Flaw — Any Chrome Extension Can Silently Trigger Claude Actions
**Source:** SecurityWeek / IANS Research (July 20) · **Score:** 7/10
Manifold AI disclosed two vulnerabilities in the **Claude for Chrome** browser extension that remain unpatched through v1.0.80 (released July 7) — eight versions after being reported to Anthropic on May 21. The core flaw: the extension's click handler never validates `event.isTrusted`, so any Chrome extension with script access on claude.ai can fire 6 lines of JavaScript to silently trigger Claude actions — including reading Gmail messages, Google Docs, and Calendar entries. Anthropic acknowledged receipt but closed the tickets without shipping a fix. Active media coverage as of July 20. **If you use the Claude for Chrome extension: be aware that any other extension installed in that browser profile with access to claude.ai pages could silently read your Google data via Claude.** Mitigation until patched: keep the extension disabled or isolated to a separate Chrome profile.
🔗 https://www.securityweek.com/unpatched-claude-for-chrome-flaw-lets-extensions-read-gmail-calendar/
**Build verdict: INFORMATIONAL — security awareness. No build needed; just know this exists until Anthropic patches it.**

### 5. MCP Enterprise-Managed Authorization Goes Stable + July 28 RC Security Analysis
**Source:** TechCrunch / SecurityWeek / Akamai (July 20) · **Score:** 6/10
Two stories converged on July 20: (1) MCP's **Enterprise-Managed Authorization** (EMA) extension promoted to stable — orgs can now tie MCP server access to their IdP (Okta, Azure AD, etc.) for zero-touch OAuth, replacing per-server consent prompts. (2) Security researchers published analysis of the new July 28 RC, identifying three new attack vectors introduced by the spec changes: **stored XSS via MCP Apps** (new server-rendered UI layer), **DoS via async tasks** (attackers initiate expensive long-running tasks then disconnect), and **workflow hijacking via predictable tracking identifiers** (stateless core uses IDs that can be guessed). The 12-month deprecation window means existing servers don't break July 28, but the new attack surface is live from the day the spec publishes.
🔗 https://techcrunch.com/2026/07/20/ais-most-important-protocol-is-getting-a-little-bit-easier-to-use/
**Build verdict: INFORMATIONAL — EMA is enterprise-focused (not your stack). Security analysis is awareness-only.**

### 7. 1Password for Claude — Touch ID Credential Injection Without Exposing Secrets to Claude
**Source:** HN item 48935507 / 1password.com (July 16-17) · **Score:** 5/10
1Password launched an integration (macOS Desktop, Claude Pro/Max/Team/Enterprise) where Claude can request credentials from 1Password for website login without the password ever entering Claude's context or Anthropic's systems.
