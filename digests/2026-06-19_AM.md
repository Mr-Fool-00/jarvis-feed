### 2. Agent Skill Loader MCP (back1ply/agent-skill-loader) ⚠️ Safety gate applied
**Source:** GitHub trending (PulseMCP adjacent) · **Score:** 5/10

`back1ply/agent-skill-loader` (GitHub, Feb 2026, ~1.2K stars) is an MCP server that bridges a Claude Code skills library to any MCP-compatible client. It exposes three tools: `list_skills` (returns all SKILL.md files in a configured directory), `read_skill` (returns a specific skill's content), and `invoke_skill` (runs a skill via subprocess). The README describes it as enabling "any MCP client to access Claude Code skills even if they don't natively support the CC skill format."

**Step 4.5 safety gate applied.** Issues: (a) `invoke_skill` calls subprocess with the skill content passed as a shell argument — potential command injection if skill names contain shell metacharacters. The README doesn't mention sanitization. (b) No signature verification on skill files before invocation — a malicious skill in the configured directory would be executed silently. (c) Upstream activity: last commit Feb 12, 2026. 4 open issues, no recent maintainer responses. Decision: not recommending installation. The pattern (MCP bridging skills to non-CC clients) is valid; the implementation has unresolved security surface.

🔗 https://github.com/back1ply/agent-skill-loader

**Build verdict:** INFORMATIONAL (safety gate: do not install). If Leo wants cross-client skill access, the safer path is building a minimal MCP tool that reads and returns skill content without subprocess invocation — avoids the injection surface entirely.
