### 2. "Lost in Stories": arxiv:2603.05890 — LLMs have measurable consistency bugs in long story generation
**Source:** arxiv.org · **Score:** 6/10

Published March 2026 (missed by this feed until now). 6 LLMs tested across 500+ stories from 4 benchmarks. Key findings:

- All models tested have **character-consistency failures** in stories >5,000 tokens — character motivations, backstory details, and relationships degrade predictably past this threshold
- **Plot inconsistency** (contradicting earlier established facts) spikes at scene transitions and chapter breaks
- Best-performing model (Fable 5, ironically) still failed ~23% of consistency checks in 10,000+ token stories
- **Chunked generation with explicit memory injection** reduces consistency failures by ~38% vs. straight prompting

The paper proposes a "Consistency Audit" methodology: generate → extract character/plot facts → re-prompt with explicit consistency constraints → regenerate failing sections. It's not a model fix, it's a prompting protocol.

**Why it matters:** Direct hit on Leo's fiction pipeline. The "memory injection" finding aligns with what Jarvis already does (JARVIS_PERSONA.md memory sections) — but the 38% improvement number gives a calibration target. If Leo's fiction pipeline isn't doing explicit consistency-checking between chapters, it's failing ~23% of the time and probably not catching it.

**Build verdict:** BUILDABLE — a `StoryConsistencyAudit` skill that extracts character/plot facts per chapter, checks against prior chapters, and surfaces contradictions before Leo reviews. Leo approves the approach → Jarvis builds it.
🔗 https://arxiv.org/abs/2603.05890

### 7. MEM1 (arxiv:2506.15841): memory + reasoning synergy for long-horizon tasks — 3.5x performance gain
**Source:** arxiv.org · **Score:** 5/10
MEM1 (June 2026) tests memory-augmented reasoning chains on long-horizon tasks. Core finding: agents with access to working memory (retrieved context from prior steps) plus a reasoning layer (chain-of-thought over that memory) outperform pure reasoning agents by 3.5x on tasks requiring 50+ sequential steps. The synergy effect is non-linear — memory alone +1.8x, reasoning alone +1.4x, combined +3.5x. Directly relevant to multi-chapter fiction generation where character facts from chapter 1 need to inform decisions in chapter 15.
**Build verdict:** INFORMATIONAL — confirms direction of Leo's memory injection work. No immediate build surface; supports the `StoryConsistencyAudit` direction above.
🔗 https://arxiv.org/abs/2506.15841
