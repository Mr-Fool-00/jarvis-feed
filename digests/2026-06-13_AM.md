### 2. CC v2.1.172 (June 10): Sub-agents can now spawn their own sub-agents — up to 5 levels deep
**Source:** code.claude.com/docs/en/changelog · **Score:** 9/10

For most of 2026, "subagents cannot spawn other subagents" was a hard rule in the CC docs — a deliberate guardrail against infinite recursion. That rule broke on June 10. v2.1.172 ships one line of changelog: *"Sub-agents can now spawn their own sub-agents (up to 5 levels deep)."*

How it works: each level carries its own system prompt and model; the parent reads only the leaf's summary. Each branch costs ~7× tokens. The practical sweet spot is depth 2-3 — depth 1 = what Leo already does, depth 2 = orchestrator spawning writers, each writer spawning scene-agents, depth 3 = adding a separate reviewer layer per scene.

Also in v2.1.172: marketplace plugin search bar in `/plugin`, fix for 1M-context sessions getting stuck without credits, fix for `availableModels` restrictions not applying to subagent overrides.

**Why it matters:** This is the missing primitive for Leo's /book-pipeline architecture. The full stack now looks like: `book-coordinator` → `chapter-writer[N]` (parallel, 3 agents) → each spawning `scene-fixer` or `continuity-checker` sub-agents on demand. The 3-tier Sonnet/Haiku/Haiku cost model is now achievable without hacking it. The Barr Group 3W+3E+4R pattern from the agent suggestions fits natively into depth-2 nesting. This is the enabling primitive Leo's been waiting for.

**Build verdict:** BUILDABLE — enables the depth-2 fiction pipeline architecture. See briefing: `briefings/2026-06-13_nested-subagents-fiction-pipeline.md`
🔗 https://github.com/anthropics/claude-code/releases/tag/v2.1.172
