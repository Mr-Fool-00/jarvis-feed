### 2. Anthropic: AI Code Migration at Scale — 8-Reviewer Parallel Review Pattern (July 24)
**Source:** claude.com/blog/ai-code-migration · **Score:** 8/10

Anthropic's official methodology post for large-scale code migrations using Dynamic Workflows. Two real case studies: Jarred Sumner migrated 1M lines Zig→Rust in under 2 weeks; Mike Krieger moved 165K lines Python→TypeScript in a weekend. The documented core architecture: **8 specialized parallel review subagents per migration chunk**, each owning one review dimension (type safety, test coverage, API surface, security, performance, documentation, platform idioms, regression), all running concurrently before a judge synthesizes verdicts. Phase gates block advancement until all 8 reviewers sign off. Three adversarial review rounds after each migration phase.

**Why it matters:** The 8-reviewer parallel architecture maps directly onto chapter quality review in Leo's fiction pipeline. Swap the migration dimensions for fiction dimensions (voice consistency, character continuity, pacing, dialogue authenticity, sensory detail, plot logic, world-bible compliance, handoff fidelity) and you have a production-tested recipe for parallel chapter review. The phase gate + adversarial round pattern prevents low-quality chapters from propagating into the next arc. Briefing filed.
