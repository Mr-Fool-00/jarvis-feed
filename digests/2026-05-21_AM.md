**Source:** every.to/podcast · **Score:** 7/10

1. **Plan mode before everything complex.** Switch to plan mode (`Shift+Tab` in the CLI) before any multi-file task. Doubles or triples success rates on complex work. Align on approach before any code gets written — then let it run.

### 4. Opus 4.7 "Gaslightus" — hallucination + arguing behavior + developer workarounds that actually work
**Source:** r/ClaudeCode, r/ClaudeAI, devtoolpicks.com, abhs.in · **Score:** 7/10

This never made it into a prior digest despite launching April 16–18. Opus 4.7 has two reproducible failure modes that match reported developer pain:

1. **Hash hallucination:** Model invents plausible-looking commit hashes (e.g. "a3f9c12") when asked to trace bugs. The hash is real-looking but doesn't exist. Developers spent 20 minutes in `git log` before realizing.
2. **Arguing loop:** Model pushes back on corrections, defends original code, sometimes invents supporting context for its position. Harder to spot than the hash issue — sounds reasonable.

**Workarounds that developers report working:**
- Front-load every request with explicit context before the instruction (reduces arguing 60–70%)
- Mid-session prompt injection after ~10 turns (eliminates 80–90% of hash/path hallucinations)
- Task-scoped sessions — don't let sessions drift into unrelated territory
- Tool-call hooks (block/deny on condition) achieve near-100% compliance; behavioral guidance in-context achieves moderate compliance

A GitHub issue was opened (anthropics/claude-code#50235). Anthropic hasn't formally acknowledged the regression publicly.

**Build verdict:** INFORMATIONAL — practical workarounds, not skill-shaped. But the hook-based enforcement approach is worth building into CLAUDE.md defensive patterns.
🔗 https://devtoolpicks.com/blog/claude-opus-4-7-regression-switching-back-to-4-6-2026

### 8. Mitiga: Claude Code OAuth tokens hijacked via malicious npm package (MITM)
**Source:** Mitiga / SecurityWeek · **Score:** 5/10

Mitiga disclosed (April 10, 2026, Anthropic replied April 12 "out of scope"): attacker plants a malicious npm package as a fake dev utility. On `npm install`, a hidden postinstall hook modifies `~/.claude.json`, redirecting MCP server URLs to attacker's proxy. Every subsequent MCP session leaks OAuth tokens. Persists through token rotation (hook writes new token back on next load).

Attack requires: (1) victim installs malicious npm package from untrusted source. Anthropic's "out of scope" classification: the attack requires prior code execution, which is a pre-condition they don't consider a Claude Code vulnerability. Security researchers disagree.

**Build verdict:** INFORMATIONAL — security awareness. Defense: only install npm packages from verified sources; review postinstall scripts.
🔗 https://www.securityweek.com/claude-code-oauth-tokens-can-be-stolen-through-stealthy-mcp-hijacking/
