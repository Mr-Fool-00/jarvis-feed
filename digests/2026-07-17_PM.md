### 2. arxiv:2607.05577 — Narrative World Model: Narratology-Grounded Writer Memory `arxiv:2607.05577-narrative-world-model` · Score: 8/10

**Source:** arXiv (cs.CL) · Kelly Hong, Anton Troynikov, Jeff Huber · July 7, 2026  
**Why it matters:** Proposes a typed temporal-state graph for tracking narrative state during long-form fiction generation. The graph tracks: **focalization** (whose POV is active), **epistemic state** (who knows what within the story world), **event-vs-reveal order** (when events happen vs. when readers learn of them), **dramatic function** (each scene's structural role), **promise/payoff pairs**, and **validity intervals** (when each fact is true). A query-conditioned hybrid retriever (BM25 + vector + one-hop graph expansion) fetches the relevant subgraph for each generation step, rather than dumping the full history into context.

Key results: outperforms single-model baselines on multi-hop narratological QA. The epistemic state tracking specifically kills a major LLM fiction failure mode — characters revealing information they couldn't know yet.

**Leo relevance:** This is the memory layer the fiction pipeline is missing. The "who knows what" epistemic graph directly addresses the continuity errors that make multi-chapter CC drafts feel inconsistent. The promise/payoff tracker is a native implementation of what the StoryWriter paper's story-bible tries to do informally. The hybrid retriever is buildable as a CC skill that wraps the graph queries.

**Build_worthy:** YES — see briefing. The typed graph structure maps cleanly onto a YAML story-bible + graph-query CC skill. Buildable now.

🔗 https://arxiv.org/abs/2607.05577

### 3. "Friendly Fire" — Defensive CC Agents Hijacked via Prompt Injection for RCE `security:friendly-fire-exploit-2026-07` · Score: 7/10

**Source:** AI Now Institute · July 8, 2026  
**Why it matters:** Demonstrates that autonomous CC agents running in code-review mode can be turned against the operator via prompt injection in third-party library files. The attack surface: a geopy clone with payload binary, decoy .go file, wrapper script, and a poisoned README. When CC's auto-mode agent reviews the repo, the README injection redirects its tool calls to execute the payload — no auth bypass, no user interaction, pure context manipulation. Confirmed on CC with Sonnet 4.6, Sonnet 5, and Opus 4.8.

The structural problem: CC's agent mode by design executes bash/file operations, and the system prompt is not privileged enough to prevent a sufficiently compelling in-context instruction from overriding it. The AI Now brief frames this as a systemic issue rather than a CC-specific bug.

**Leo relevance:** Relevant for any CC pipeline that processes untrusted third-party code — fiction tools that ingest reader-submitted content, any automated code-review workflow. The defensive pattern is: never run auto-mode against untrusted repos without a sandboxed worktree AND human-in-the-loop approval of bash operations.

**Build_worthy:** No — security alert. The defensive guidance is: don't process untrusted content in full-auto mode.

🔗 https://ainowinstitute.org/publications/friendly-fire-prompt-injection-agentic-coding

### 4. arxiv:2605.27878 — Narrative Flattening: Post-Training Compresses LLM Fiction Style `arxiv:2605.27878-narrative-flattening` · Score: 7/10

**Source:** arXiv (cs.CL) · Zehan Li et al., Knowledge Lab, U Chicago · May 27, 2026  
**Why it matters:** Empirical diagnosis of why Claude's fiction output reads tonally neutral and stylistically homogeneous: the culprit is post-training (SFT → DPO → RLVR). Each stage progressively compresses thematic transitions, regresses high-intensity emotion toward a neutral baseline, and shrinks the variance of stylistic choices. Professional literary fiction is affected more than genre pulp because it has higher baseline stylistic variance. RLVR (reinforcement learning with verifiable rewards) was the worst offender — likely because stylistic diversity has no clean verifiable signal to reward.

This is not a CC bug or a prompting problem — it's baked into the model. The mitigations: explicit contrastive examples in system prompts (show the target style AND an anti-target), in-context stylistic anchoring (paste a passage from the target author), and temperature/top-p variance tuning. The Narrative World Model (item 2) addresses the *structural* failure; this paper addresses the *stylistic* one.

**Leo relevance:** If the fiction pipeline output reads "fine but bland," this is the mechanism. The practical implication: style-inject hard via system prompt with author examples, not via vague instructions ("write like Cormac McCarthy"). Concrete author passages in the CC skill's system prompt outperform style descriptors.

**Build_worthy:** No — diagnosis, not a buildable pattern. But directly informs how to configure the fiction pipeline's system prompt.

🔗 https://arxiv.org/abs/2605.27878
