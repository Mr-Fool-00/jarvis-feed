### 2. Agentjacking: fake Sentry error hijacks Claude Code, Cursor, Codex — 85% success rate
**Source:** Tenet Security / The Hacker News · **Score:** 8/10

Tenet Security (Ron Bobrov, Barak Sternberg, Nevo Poran) published June 12 2026. Attack vector: attacker crafts a malicious Sentry error event via a single unauthenticated HTTP POST using a public Sentry credential. When a developer tells Claude Code to "fix unresolved Sentry issues," the agent queries Sentry via MCP, receives the malicious event, and executes attacker-controlled code with full developer privileges. 85% success rate across Claude Code, Cursor, and Codex. 2,388 organizations are simultaneously targetable with a single POST. Exfiltration payload: env vars, Git credentials, private repo URLs, developer identities. Sentry responded by blocking the specific payload string — reactive, not architectural. The underlying MCP trust boundary architecture remains unfixed.

**Why it matters:** If you ever wire a Sentry MCP into your Jarvis pipeline or Claude Code sessions, this attack is live today. Sentry's fix is a denylist patch on the known string — a motivated attacker bypasses it with a minor variation. The real fix is agent-level: never auto-execute MCP outputs without a human-approval checkpoint before tool use. The datasette-agent 0.2a0 pattern below directly addresses this class of problem.

🔗 https://tenetsecurity.ai/blog/agentjacking-coding-agents-with-fake-sentry-errors/

**Build verdict:** INFORMATIONAL — security awareness. No skill to build, but directly shapes how you should design any MCP integration that touches external error data.

### 5. SuperWriter: MCTS for long-form generation — plan → draft × 20 → refine × 60 → judge backprop
**Source:** arxiv 2506.04180 · **Score:** 6/10

June 4 2026 paper (missed by run gap). SuperWriter-Agent uses Monte Carlo Tree Search over a multi-stage writing pipeline: starts with 5 distinct plans, each produces 4 drafts (20 total), each draft is refined 3 times (60 final outputs), a judge LLM ranks all 60 outputs, and rankings are back-propagated through refinement and planning stages for DPO training. The result: a 7B SuperWriter-LM that produces significantly more coherent long-form text. Key insight — coherence problems in long-form generation come from models committing to a plan too early. MCTS forces exploration of the plan space before committing.

**Why it matters:** The core insight maps directly to your writing pipeline: if you're having coherence issues across chapters, the problem is likely early plan lock-in. Even without MCTS training, you could implement a manual version: generate 3-5 chapter outlines, score them with an Opus judge, pick the best before writing. That's the 20% of the technique that gets you 80% of the benefit.

🔗 https://arxiv.org/abs/2506.04180

**Build verdict:** INFORMATIONAL — academic paper with no directly installable skill. The outline-diversity idea is adaptable to your pipeline manually.
