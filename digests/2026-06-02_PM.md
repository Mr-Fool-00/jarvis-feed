### 2. CC v2.1.160 — Dynamic Workflow Keyword Renamed to `ultracode`
**Source:** code.claude.com/docs/en/changelog · **Score:** 7/10  
Today's release renames the dynamic-workflow trigger keyword from `workflow` to `ultracode` (highlighted in violet in the UI). Prompts containing the word "workflow" no longer auto-launch a dynamic workflow — you now say "ultracode" or use /effort ultracode to enable it. Also in this release: `acceptEdits` mode now prompts before writing build-tool config files that grant code execution (`.npmrc`, `.yarnrc*`, `bunfig.toml`, `.bazelrc`, `.pre-commit-config.yaml`, `.devcontainer/`), plus a prompt before writing to shell startup files (`.zshenv`, `.zlogin`, `.bash_login`). WSL clipboard fixed via PowerShell interop, background session history no longer lost on overnight retire, and CJK IME input cursor position fixed.  
**Why it matters:** If you have any prompts, skills, or CLAUDE.md instructions that say "workflow" expecting to trigger Dynamic Workflows, they silently stopped working today. The keyword you need is now `ultracode`. The security improvements (startup file + build config prompts) are real safety wins for Jarvis's cron environment — they reduce the blast radius of a misconfigured skill accidentally writing to `.zshenv` or `.npmrc`. Worth a quick search for "workflow" in your skills and command files.  
**Build verdict:** INFORMATIONAL — changelog awareness; action is a find-and-replace in your own prompts  
🔗 https://code.claude.com/docs/en/changelog

### 3. Microsoft Cancels Claude Code Licenses — Cost Killed What Engineers Loved
**Source:** Windows Central, Sesame Disk, AI Weekly, HN 48238896 · **Score:** 6/10  
Microsoft is canceling most internal Claude Code licenses across its Experiences & Devices division (Windows, M365, Outlook, Teams, Surface), deadline June 30. Engineers are being moved to GitHub Copilot CLI at $39/seat flat vs Claude Code's $20 base + API token overage. The kicker: they're canceling because engineers used it too much — Uber deployed it to 5,000 engineers and saw $500-$2,000/engineer/month in API costs. Microsoft's E&D division runs many thousands of devs; that math doesn't close. Developers are not happy.  
**Why it matters:** This validates your bet on the Max plan. The flat-rate Max model is essentially the enterprise pricing failure inverted — you get unlimited interactive Claude Code for $200/month no matter how much you use it. Microsoft's problem is they're paying per-token at scale; you're not. The pattern here is that agentic coding at high usage breaks enterprise per-token pricing, which is why Anthropic is now also separating the credit pools for programmatic usage (see item #1). The flat-rate subscribers who use Claude Code heavily are the ones getting the real deal right now.  
**Build verdict:** INFORMATIONAL — market signal; no action required, but useful context for understanding why Max plan is valuable
