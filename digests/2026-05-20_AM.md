## 🔥 Top 3

### 1. Microsoft Conductor — deterministic multi-agent orchestration via YAML
**Source:** github:microsoft/conductor · **Score:** 9/10
Microsoft open-sourced Conductor (MIT license), a CLI tool that defines multi-agent workflows in YAML with deterministic routing. Unlike frameworks that burn tokens on an LLM orchestrator deciding who to call next, Conductor uses Jinja2 templates and expression evaluation — zero-token orchestration. Supports parallel execution, shell command steps, human approval gates, and a web dashboard with interactive DAG visualization. Works with both GitHub Copilot SDK and Anthropic Agents SDK, so you can mix Claude models per agent.
**Why it matters:** This is the architecture your fixer pipeline and Council skill want to be. Your current chain (FIXER_01 through FIXER_14 → VERIFY_15 → QC) is exactly a "code review pipeline" pattern Conductor was built for. YAML definition means version-controlled pipeline configs, deterministic routing means no token waste on orchestration, and parallel execution means independent fixers could run concurrently. The fact that it speaks Anthropic Agents SDK natively means migration from your current sequential chain could be incremental.
🔗 https://github.com/microsoft/conductor

**Source:** hn:47160980 · **Score:** 8/10
