## What shipped

OpenAI GA'd GPT-5.6 on July 9 as a three-tier model family (Luna/Terra/Sol):

| Model | Input | Output |
|-------|-------|--------|
| Luna  | $1/M  | $6/M   |
| Terra | $2.50/M | $15/M |
| Sol   | $5/M  | $30/M  |

For comparison: Claude Sonnet 4.6 is approximately $3/$15; Fable 5 is ~$10/$50 per 1M tokens.

## The number that matters: Agents' Last Exam

Sol scores **53.6** on Agents' Last Exam. Fable 5 scores approximately **40.5**.

That's a 13+ point gap on long-running professional agent workflows — tasks that take >30 minutes of autonomous agent time, involve multi-hop tool use, and require sustained reasoning quality. This is the hardest current benchmark for production agent performance.

This is the first time a non-Claude model has led on the agent benchmark that matters most for the use cases the Jarvis stack targets.

## The agent-relevant capability additions

### Multi-agent as first-class API primitive

Sol can now spawn subagents natively through the API — models call out to parallel focused instances for subtasks. This is architecturally similar to CC's agent spawning. Previously this required building a wrapper layer; now it's a parameter.

### Prompt cache breakpoints (Sol)

Explicit cache control — mark specific points in a prompt as cache anchor points. Similar to Claude's prompt caching but with more manual control. Relevant for long-running sessions where you want to avoid re-processing a large context prefix.

## What this means for Leo's stack

Leo is Claude-focused, and there are no immediate action items. But:

1. **The agent gap has closed.** Fable 5 was previously the clear leader on agent benchmarks. It is no longer. On the benchmark that matters most for long-running agent work, OpenAI now leads.

2. **Pricing pressure.** Sol at $5/$30 is cheaper than Fable 5 at $10/$50. If Sol quality closes the remaining gap, there will be a cost argument for switching orchestrator model.

3. **Watch for Anthropic response.** A 13-point Agents' Last Exam gap is large enough that Anthropic will respond. Expect either a Fable 5 update or a new model announcement addressing agent performance specifically.

## Simon's take

Simon's writeup is worth reading in full (link above). He notes that the multi-agent API primitive is the highest-leverage addition for production agent builders — it removes a layer of wrapping code that currently exists in nearly every multi-agent framework.
