### 1. Anthropic: J-space — Claude's global workspace for silent reasoning · 8/10

Brand-new Anthropic interpretability paper (July 6–7, 2026), 16 authors. The J-lens technique (Jacobian-based dimensionality probe) reveals "J-space": a privileged, sparse subspace where Claude holds verbalizable concepts *before* output begins. This is the internal workspace where reasoning happens, not the residual stream.

Five functional properties found, all matching Global Workspace Theory from cognitive neuroscience:
1. **Sparse activation** — only ~15% of J-space neurons fire per token
2. **Global broadcasting** — J-space activations influence many downstream heads simultaneously  
3. **Temporal priority** — concept representations in J-space lead output by 3-7 forward passes
4. **Verbalizable content** — steering J-space neurons directly changes what Claude "thinks" without changing surface behavior immediately
5. **Prompt injection detection signal** — when reading injected prompts, J-space contains "injection"/"fake" concepts *before* the output reflects them

That last point is the operational takeaway. This gives a real, model-internal monitoring channel for detecting whether Claude "noticed" an injection attempt during a task — not after the fact from output, but live from J-space. Anthropic open-sourced the J-lens probing code (linked from paper).

### 2. Alibaba bans Claude Code — confirms China-detection backdoor · 8/10

This was in the July 5 run as a surface-level item (scored 7/10 as "SCMP: Alibaba bans CC"). The full technical story has now broken and it's materially different.

**What was actually shipped (CC v2.1.91, April 2, 2026):**
- XOR(0x5B) obfuscated code silently fingerprinted sessions routed through Chinese infrastructure
- Detection heuristics: timezone check (Asia/Shanghai / Asia/Urumqi) + lookup against a 147-entry Chinese domain list
- Positive matches flagged by encoding *steganographic signals* in the system prompt: date separator dash→slash swapped, apostrophe replaced with 3-character Unicode lookalike sequence
- The system prompt flag persisted into all downstream completions — meaning affected sessions generated subtly different outputs than non-flagged sessions

**What happened:**
- Anthropic engineer Thariq Shihipar confirmed July 1: "experiment launched in March" to detect unauthorized resellers operating in China without Anthropic authorization
- Stripping PR merged July 1. Feature is gone in v2.1.200+.
- Alibaba employee deadline: stop using CC entirely by July 10 or face disciplinary action
- Internal Alibaba classification: "high-risk spyware"

**Why the score is now 8 not 7:** The steganographic output-level impact is a new fact. This wasn't just telemetry — flagged sessions produced different output tokens than clean sessions. That crosses from "tracking" into "behavior modification based on inferred geolocation." Whether you call it a safety net or a backdoor depends on your threat model, but it's factually different from what the July 5 item described.

### Claude Code: DNS TXT record → reverse shell · 7/10

SecurityWeek (July 7): distinct from the code-comment injection in the AM digest. Attack vector: poison a DNS TXT record for a domain CC resolves during a task (e.g., a package registry, a CDN). The TXT payload contains injected instructions. No repo modification needed — payload is hot-swappable without touching any file the user would review. The demo showed a reverse shell established via a crafted TXT record on an attacker-controlled domain.

Mitigation: don't allow CC agentic runs to resolve untrusted external domains without content filtering.
