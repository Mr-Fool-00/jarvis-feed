### 1. Claude Code v2.1.217 — Subagent concurrency controls land 🏗️
**Score: 8/10** · Source: github.com/anthropics/claude-code · Released: 2026-07-21 21:35 UTC

The most operationally relevant release in weeks for multi-agent workflows:

- **`CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS`** — new env var, default cap **20**. Set lower to avoid token floods on tight budgets.
- **`CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH`** — nested subagents **disabled by default**. Opt-in required for recursive agent trees.
- **`--max-budget-usd` now enforced across background subagents** — previously only guarded the foreground process; background agents could breach the cap.
- MCP memory leak fix (persistent across long sessions)
- CLAUDE.md brace expansion OOM fix — if your CLAUDE.md used `{a,b,c}` patterns, this prevented startup
- Background session symlink isolation fix — multiple concurrent sessions no longer collide on temp paths

**Why it matters**: The concurrency cap and spawn-depth gate directly change how orchestration pipelines should be structured. Pipelines that relied on implicit unlimited concurrency need explicit env var configuration now.

**URL**: https://github.com/anthropics/claude-code/releases/tag/v2.1.217
