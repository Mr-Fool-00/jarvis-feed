### 2. MCP & Agent Security Wave: 4 Attack Vectors in 72 Hours
**Source:** The Hacker News / Help Net Security / Adversa AI · **Score:** 7/10

Four separate security stories dropped between July 27–29, all converging on the same message: MCP and Claude extensions are now high-value attack surface. Individually each is notable; together they're a pattern.

**Attack #1 — FakeGit campaign (July 21, Help Net Security):**
Attackers poison AI agent recommendations with malicious GitHub repos. When Claude Code searches for libraries or repos during a session, it can be manipulated via search result injection to recommend repos that install backdoors. This is live and ongoing.
🔗 https://www.helpnetsecurity.com/2026/07/21/github-repos-malware-campaign-fakegit-ai-agents/

**Attack #2 — Microsoft Azure DevOps MCP Flaw (The Hacker News):**
Hidden comments in pull requests can hijack AI review agents connected via MCP, redirecting their behavior without any visible indicator in the PR UI. If you use an MCP-connected code review agent, it can be silently redirected.
🔗 https://thehackernews.com/2026/07/microsoft-azure-devops-mcp-flaw-lets.html

**Attack #3 — Claude Cowork / Claude for Chrome VM escape (The Hacker News):**
Security flaw allows an agent using Claude Cowork to escape its VM and read macOS files. A separate Claude for Chrome flaw lets malicious browser extensions hijack Claude and access Gmail, Docs, and Calendar.
🔗 https://thehackernews.com/2026/07/claude-cowork-flaw-could-let-ai-agent.html
🔗 https://thehackernews.com/2026/07/claude-for-chrome-flaw-lets-other.html

**Attack #4 — Ruflo CVE-2026-59726 (CVSS 10.0):**
Open-source agent meta-harness for Claude Code and Codex has an unauthenticated remote code execution via its unprotected MCP bridge endpoint. If anyone has Ruflo installed and the bridge is exposed, full compromise is possible with no auth required.

**Why it matters:** FakeGit is the most immediate risk for your workflow — if you ever let CC search GitHub and auto-clone a suggested repo, you're in scope. The Chrome extension flaws apply if you use Claude for Chrome. Adversa AI July roundup has the full CVE list: https://adversa.ai/blog/top-mcp-security-resources-july-2026/

**Build verdict:** INFORMATIONAL — security awareness required. No buildable skill. However: adding a CLAUDE.md rule like "ALWAYS verify any GitHub repo before cloning, do not auto-install from search results" is worth doing manually.

🔗 https://adversa.ai/blog/top-mcp-security-resources-july-2026/
