**Source:** github.com/anthropics/claude-code/releases · **Score:** 8/10

Released July 15 at 23:02 UTC. Closes out the v2.1.208–210 sprint with a wide-coverage release.

**New flag — `--forward-subagent-text` (and `CLAUDE_CODE_FORWARD_SUBAGENT_TEXT` env var):** Includes subagent text output and thinking blocks in stream-json output. For Jarvis: Jarvis's background agent sessions can now stream their inner monologue to the parent — enables real-time visibility into what the sub-agents are doing during a discovery run without waiting for their final result.

**Security — Unicode bidirectional-override hardening:** Permission previews relayed to Slack/chat channels were susceptible to bidirectional Unicode, zero-width characters, and look-alike quotes being planted in filenames or tool arguments — an attacker who could get a malicious string into a tool call could make the permission preview look safe when it wasn't. Now neutralized.

**Other notable fixes:**
- Parallel CC sessions all logging out simultaneously after wake-from-sleep — fixed
- Subagent model override reverting to parent model mid-run — fixed
- `/clear` not resetting session cost counter — fixed
- Plugin MCP servers not reconnecting after idle web sessions — fixed
- Prompt-caching regression on Bedrock/Vertex/Mantle/Foundry — fixed
- `always allow` rules now save at repository root (not home directory) — behavioral change to be aware of
- Scientific notation support for integer env vars (`1e6`, `64_000`) — useful for large-context config
- Improved terminal layout/rendering performance
- 30+ additional fixes

**Build verdict: INFORMATIONAL — run `npm update -g @anthropic-ai/claude-code`. The `--forward-subagent-text` flag is directly useful for Jarvis monitoring. Set `CLAUDE_CODE_FORWARD_SUBAGENT_TEXT=1` in the cron environment to enable.**

### 2. Claude Code Agent View + /goal Command (Research Preview)
**Source:** Geeky Gadgets / YouTube · **Score:** 8/10

Announced approximately July 13-14 in a research preview. Two features bundled:

**Agent View dashboard:** A single view showing all active background Claude Code sessions — what each is doing, its current tool call, and estimated progress. You can kill, attach, or inspect any session from one place. For Jarvis: this is exactly the visibility Jarvis's cron runs lack. Leo currently can't see what Jarvis is doing mid-run without tailing logs; Agent View surfaces it natively.

**`/goal` command:** Sets an autonomous completion condition that Claude checks after each tool call. When the condition is met, Claude stops without being interrupted mid-tool. Eliminates the "overshoot" problem where background agents keep going after they've answered the question.

**Ctrl+X:** Clears all background sessions at once — panic button for runaway multi-agent states.

**Why it matters to Jarvis:** These three features together move background session management from "hope it worked" to "watch it work." The /goal command in particular could replace Jarvis's current hard-budget-check heuristic with a condition the agent itself can evaluate.

**Availability:** Research preview; may not be on all plans yet. Watch for rollout to Max.

**Build verdict: INFORMATIONAL — watch for Max plan rollout. When it lands, update Jarvis's cron environment to use Agent View for session monitoring and add a `/goal` condition to each run.**

🔗 https://www.geeky-gadgets.com/claude-code-agent-view-update/
🔗 https://www.youtube.com/watch?v=-jINRoST0mk

### 5. Claude for Chrome v1.0.80 — Unpatched Gmail/Docs/Calendar Flaw (8 Weeks Open)
**Source:** The Hacker News / Manifold Security · **Score:** 7/10
Two vulnerabilities reported by Manifold Security on May 21 against v1.0.72 — (1) synthetic click injection and (2) privilege escalation via `?skipPermissions=true` URL — allow any malicious browser extension to hijack Claude for Chrome and silently read Gmail, Google Docs, and Calendar data while Claude's hands-off/agentic mode is active. Anthropic acknowledged both vulnerabilities the next day, then closed the reports without patching. Eight releases later, v1.0.80 (July 7) contains byte-for-byte identical vulnerable code. No CVE assigned; no patch ETA as of July 14.
**Action for Leo:** If you have Claude for Chrome installed and agentic mode enabled, any malicious extension in your browser profile can currently read your Gmail. Either disable agentic mode or audit your extensions until a patch ships.
**Build verdict: ACTION — check your Chrome extension list for unknown/low-review-count extensions. Disable Claude for Chrome agentic mode as a precaution.**
🔗 https://thehackernews.com/2026/07/claude-for-chrome-flaw-lets-other.html
