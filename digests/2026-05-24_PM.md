### 1. How Anthropic Built a C Compiler with 16 Parallel Claude Agents
**Source:** anthropic:building-c-compiler · **Score:** 8/10
Anthropic's engineering blog (published February 2026, not previously surfaced). 16 Claude agents on a shared Git repo built a 100,000-line Rust-based C compiler capable of compiling Linux 6.9, SQLite, PostgreSQL, FFmpeg, and QEMU — over ~2,000 Claude Code sessions, $20K in API costs. The coordination architecture is the part that matters: **no message bus, no task queue, no orchestration framework.** Just Git. Each agent claims a task by writing a lock file (`current_tasks/parse_if_statement.txt`). If two agents try to claim the same task, the merge conflict tells the second agent to pick something else. That's it.

**Why it matters:** Leo runs multiple agents in his writing pipeline — but right now each run is serial or manually coordinated. This Git-lock pattern works at scale without any infrastructure overhead. A chapter-generation pipeline with 8 parallel agents claiming scene tasks via Git lock files is a direct lift from this architecture. The case study also shows exactly how to structure agent task decomposition: small, claimable, independently verifiable units. "Write chapter 3 scene 2 from the hero's POV" is the same shape as "parse if statement."
Build verdict: INFORMATIONAL — case study; patterns for Git-based parallel agent coordination are directly applicable to Leo's writing pipeline without installing anything
🔗 https://www.anthropic.com/engineering/building-c-compiler
