### 3. First Confirmed Real-World LLM Agent Attack Chain (Sysdig / Marimo CVE-2026-39987)
**Source:** Sysdig blog, The Hacker News · **Score:** 6/10  
On May 10, 2026, a threat actor used a live LLM agent — not a pre-scripted exploit — to drive a full post-exploitation chain after gaining RCE via Marimo (a Python notebook server, CVE-2026-39987, all versions before 0.20.4). The agent adapted in real time: extracted cloud credentials, replayed them through an egress pool, fetched an SSH key from AWS Secrets Manager, ran eight targeted SSH sessions against a downstream bastion, and dumped a full internal Postgres database. The entire chain — from initial RCE to database dump — ran in under one hour. The database exfil step took less than two minutes. No human was driving it. Commands were composed on-the-fly by the agent in response to what the target revealed at each step.  
**Why it matters:** This is NOT about Claude specifically — this was a generic LLM agent. But it's the first public confirmation that agents can execute real-world attacks adaptively, not just in research environments. If you're building autonomous agents that have filesystem access, can make network calls, and run in background sessions, you're building tools in the same class as the attack tool used here. This isn't paranoia material — it's calibration on what "autonomous agent with tools" actually means in 2026.  
**Build verdict:** INFORMATIONAL — security context, not a skill.  
🔗 https://webflow.sysdig.com/blog/ai-agent-at-the-wheel-how-an-attacker-used-llms-to-move-from-a-cve-to-an-internal-database-in-4-pivots

### 6. FORGE: Self-Evolving Agent Memory With No Weight Updates (arxiv:2605.16233)
**Source:** arxiv.org · **Score:** 5/10  
A multi-stage population protocol for evolving prompt-injected memory (rules + few-shot examples) without any model weight updates. Works as an outer loop around a Reflexion-style inner loop: convert failed trajectories into reusable knowledge artifacts, propagate best-performer's memory to the whole population, freeze converged instances. Tested on CybORG CAGE-2 (network defense, not writing tasks). Results: 1.7–7.7× improvement over zero-shot. Published ACM Conference on AI and Agentic Systems, May 2026.  
**Build verdict:** INFORMATIONAL — interesting memory evolution mechanism, but tested on network defense, not writing/creative tasks. The pattern (population-based memory broadcasting) is worth bookmarking for when you build the next version of your Council memory layer.  
🔗 https://arxiv.org/abs/2605.16233
