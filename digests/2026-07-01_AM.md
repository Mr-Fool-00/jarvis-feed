### 2. KAIROS: Persistent Background Daemon + autoDream Memory + Steganographic Chinese-User Detection
**Source:** therealllo.dev · InternationalCyberDigest · Zscaler Research · StreetInsider · HN:48735113 · **Score:** 9/10

On March 31, 2026, Anthropic accidentally leaked Claude Code's full source code — 512,000 lines of TypeScript — via a missing `.npmignore` in a published npm package. **ultraworkers/claw-code** (a clean-room Rust rewrite of the leaked source) hit 194,400 stars, briefly ranking #25 globally on GitHub, the fastest any repo had ever climbed. Security researchers have been excavating the source since. Multi-source deep verification this run confirmed three findings:

**Finding 1 — KAIROS (Greek: "the right moment"):** A persistent background daemon that runs silently during and after CC sessions. It is feature-gated and not active for all users. Key confirmed properties:
- Polls Anthropic's settings servers **hourly** during active sessions
- Contains **6+ remote killswitches** that can disable capabilities without a client update
- Runs **autoDream** (below) after each session ends, before process termination

**Finding 2 — autoDream (4-phase memory consolidation):**
- **Orient** — scan current session transcript for notable entities, decisions, code patterns
- **Gather** — pull relevant snippets from prior sessions in `~/.claude/kairos-memory/`
- **Consolidate** — synthesize into a compressed state snapshot, **25KB hard cap**
- **Prune** — evict oldest/lowest-relevance entries to stay under cap
This gives KAIROS cross-session memory that persists beyond Claude's context window — without being visible in the conversation Claude itself has access to. Anthropic has not publicly disclosed this feature.

**Finding 3 — Steganographic Chinese-user detection (active since v2.1.91, April 2 2026):**
- **Date format encoding:** System prompts inject dates as `2026-06-30` for standard users, `2026/06/30` (slash-separated) for users whose timezone, IP geolocation, or proxy fingerprint matches Chinese mainland patterns
- **Unicode apostrophe encoding:** Standard users get U+0027 (ASCII apostrophe); detected VPN users / potential AI-lab proxies (Alibaba, ByteDance extraction patterns) get U+2019 (curly right single quotation mark) — an imperceptible difference at the UI level but a meaningful divergence in the model's framing
- Purpose: anti-distillation watermarking. Alibaba's extraction campaign (documented March–April 2026) prompted this response. Calling it "spyware" is sensationalist — but undisclosed system-prompt manipulation based on user origin is real.

**Bonus finding:** Claude Desktop auto-installs a Native Messaging host in 7 browsers (Chrome, Brave, Firefox, Edge, Arc, Vivaldi, Opera) without explicit user consent, pre-authorizing 3 Chrome extension IDs as trusted callers.

**Why it matters:** Leo's overnight fiction pipelines run as unattended CC sessions. KAIROS's hourly polling + killswitches mean a pipeline started at 10 PM can be silently reconfigured by 11 PM. The autoDream 25KB memory exists outside the conversation — it's shaping context you can't inspect. The steganographic detection isn't targeted at Leo (US timezone, no VPN), but it confirms Anthropic is injecting undisclosed variables into sessions based on user fingerprinting. These aren't reasons to stop using CC — but they ARE reasons to stop assuming sessions are clean black-boxes.

🔗 https://therealllo.dev/kairos-cc-analysis · https://news.ycombinator.com/item?id=48735113

**Build verdict:** INFORMATIONAL — not buildable, but action-worthy. If Leo wants inspectable sessions, he should keep runs under 60 minutes (minimize KAIROS polling window) and check `~/.claude/kairos-memory/` for accumulated state.
