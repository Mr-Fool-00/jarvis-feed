## What shipped

CC v2.1.221 (August 4, 2026) is the 4th release in 14 days (v2.1.218–221). Changelog highlights:

### Focus View
- Toggle: `Ctrl+Alt+F` or via the chat menu
- Collapses all tool-call activity in a session behind expandable per-turn summaries
- The chat view shows only conversation turns; tool calls (file reads, edits, bash commands) expand on click
- Designed for long agentic sessions where tool output volume drowns the narrative
- **Direct impact on Jarvis runs:** long runs currently emit hundreds of tool-call lines. With Focus View on, you see only the agent conversation; all tool steps expand on demand. Makes post-run review dramatically more readable.

### `mode: "mask"` credential masking
- Applies to sandbox credential files on Linux/WSL
- Real credentials are substituted on egress — they never leave the sandbox boundary in raw form
- Activated via `mode: "mask"` in the relevant sandbox configuration

### Bash/zsh permission-check bypass fix (security patch)
- A bypass was present where zsh could silently execute commands inside `[[ ]]` regex conditionals, bypassing CC's shell-execution permissions check
- Affected: any workflow using zsh + regex conditionals in shell scripts CC was executing
- Fixed in v2.1.221 — update today

### Other changes
- `prompt-audit` subcommand added to the `claude-api` skill
- Stats panel now breaks out cache tokens by input/output/read/write (useful for diagnosing session cost)
- `/fork` now creates a git worktree instead of a plain branch copy
- Background Session behavior change: sessions that background now suspend rather than continue running
