The "tiered authorization" idea (different approval gates for different action risk levels) is worth stealing as a design principle even if the Chinese law itself doesn't apply to you.

### 7. FARMA: Forged Reasoning Memory Attacks on LLM Agent Memory (arXiv:2607.05029)
**Source:** arxiv.org · **Score:** 6/10 · Published: July 6, 2026

Introduces FARMA — an attack where adversarially crafted content, once stored in an agent's memory layer, poisons the agent's future reasoning by injecting false "past experiences." When the agent retrieves memories to ground future decisions, the forged memories redirect its behavior. Paper also proposes defenses (memory provenance tagging, retrieval confidence gating).

**Why it matters:** Directly relevant once you build the persistent cross-session memory layer for Jarvis (on the summer roadmap). An agent that stores what it's seen and learned is also an agent that can be taught lies via poisoned input. The defense pattern — provenance tagging (know WHERE each memory came from) + confidence gating (know HOW confident the retrieval is) — is worth baking in from day one rather than retrofitting.

**Build verdict:** INFORMATIONAL — security pattern to apply when building Jarvis memory; no standalone skill yet.

🔗 https://arxiv.org/abs/2607.05029
